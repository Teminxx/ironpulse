# IronPulse

App de entrenamiento de fuerza con rangos, XP, rachas y progreso.

## Abrir la app

**https://teminxx.github.io/ironpulse/**

Ese es el enlace de la aplicación. No confundir con la dirección de este repositorio.

## Instalar en iPhone

1. Abre el enlace de la app en **Safari**.
2. Toca **Compartir**.
3. Elige **Añadir a pantalla de inicio**.
4. Pulsa **Añadir** y ábrela desde el icono nuevo.

Se abre a pantalla completa, con su propio icono y funciona sin conexión después de la primera visita.

## Instalar en Android

1. Abre el enlace en **Chrome**.
2. Menú **⋮** → **Instalar aplicación**.

## Datos

Todo se guarda en el dispositivo. Usa **Ajustes → Copia de seguridad** para exportar o restaurar un archivo JSON.
